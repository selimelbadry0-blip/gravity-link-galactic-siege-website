# Gravity Link: Galactic Siege - Official Website

Welcome to the official website repository for **Gravity Link: Galactic Siege**, an exciting space adventure game on Astrocade!

## 🚀 About the Game

Gravity Link: Galactic Siege is a strategic gameplay experience where you master gravity mechanics to solve puzzles, defeat enemies, and conquer the cosmos. Features include:

- **Strategic Gameplay** - Plan your moves carefully
- **Gravity Mechanics** - Harness the power of gravity
- **Progressive Levels** - From easy to challenging missions
- **Epic Boss Battles** - Face powerful galactic enemies
- **Smooth Controls** - Intuitive and responsive gameplay
- **Leaderboards** - Compete worldwide

This website can be deployed to various platforms:

- **GitHub Pages** - Free hosting directly from this repository
- **Vercel** - High-performance hosting with automatic deployments
- **Netlify** - Easy deployment with CI/CD integration
- **Any static host** - Just upload the HTML and CSS files

### Deploy to GitHub Pages

1. Go to repository Settings
2. Navigate to Pages section
3. Select `main` branch as source
4. Your site will be live at `https://selimelbadry0-blip.github.io/gravity-link-galactic-siege-website/`
